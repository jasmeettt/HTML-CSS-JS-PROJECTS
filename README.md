# HTML CSS JS Projects

A curated collection of interactive web projects built with vanilla HTML, CSS, and JavaScript. This repository serves as a showcase of fundamental web development skills, exploring creative UI designs and dynamic functionality without the need for heavy frameworks.

## About
These projects demonstrate the power of core web technologies:
- **HTML5** for semantic structure.
- **CSS3**, **SCSS**, and **Tailwind CSS** for modern, responsive styling and animations.
- **JavaScript (ES6+)** and **TypeScript** for interactive logic and type-safe development.

Each project is self-contained and designed to highlight specific concepts, from basic layout techniques to complex game logic.
